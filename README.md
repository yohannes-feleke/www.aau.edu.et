# MyWeb Portal

## Installation

1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

   pip install -r requirements.txt

4. Edit .env and enter your Telegram bot token and group ID.
5. Run:

   python app.py

6. Visit http://127.0.0.1:5000

The demonstration login accepts arbitrary usernames.
Passwords are not transmitted or stored.
